# 5-Minute Demo Script

## 0:00–0:35 — Problem
Show an ambiguous incident. Explain that convincing AI output is not enough: the system must justify a diagnosis and survive attempts to disprove it.

## 0:35–1:15 — Baseline
Run the deterministic baseline on the incident. Show its single keyword-driven prediction and fixed confidence.

## 1:15–2:35 — Advanced investigation
Run OpsTwin. Show the evidence timeline, competing hypotheses, supporting/counter evidence and the explicit agent loop.

## 2:35–3:25 — Verification
Run a safe sandbox verification/replay. Emphasize that consequential production actions are not executed.

## 3:25–4:15 — Measured improvement
Run the fixed benchmark and adversarial cases. Show actual measured baseline vs advanced results. Do not narrate unmeasured claims.

## 4:15–4:45 — Changelog
Show one iteration that materially improved reliability and one experiment that was removed because evidence did not justify keeping it.

## 4:45–5:00 — Close
Hot take: the best incident agent is the one whose conclusion survives attempts to disprove it. Show the reproducibility commands and repository.
