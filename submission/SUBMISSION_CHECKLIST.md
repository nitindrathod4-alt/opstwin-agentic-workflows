# Final Submission Checklist

- [ ] Baseline solution runs from a clean environment
- [ ] Advanced solution runs from a clean environment
- [ ] Fixed benchmark results recorded
- [ ] Adversarial benchmark results recorded
- [ ] Improvement Changelog links each major change to evidence
- [ ] README explains user, bottleneck, value, failure mode and hot take
- [ ] Reproduction commands tested
- [ ] Representative agent trajectories included
- [ ] No secrets or private credentials in the archive
- [ ] Consequential actions remain sandboxed/simulated
- [ ] Demo video is <= 5 minutes and link is publicly accessible
- [ ] ZIP contains source, tests, configs and required agent traces
- [ ] Latest ZIP is the only archive submitted
